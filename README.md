# Gacha Forge · 의상 캐릭터 고정 1.1.0

가챠 포지 **1.27**(Marinara Engine 2.5.2) 상점 의상 로테이션에 **월드마다 꼭 넣을 캐릭터를 고릅니다.** 로테이션당 의상 수는 게임 설정 그대로이고, 고른 캐릭터가 먼저 들어간 뒤 **남은 자리는 나머지 보유 캐릭터 중에서 무작위**로 채웁니다. 아무도 고르지 않으면 게임 기본(보유 캐릭터 전체에서 덜 받은 캐릭터부터)입니다.

예: 이미지 설정의 로테이션당 의상 수가 3벌이고 A를 고정하면 → A + 나머지 보유 캐릭터 중 무작위 2명.

커스터마이저 패치 없이도 단독으로 동작합니다.

## 구성
- `gf-outfit-pin-runtime.cjs` — 서버 훅 (메모리에서만 수정, 설치 파일은 그대로). Gacha Forge 1.27.x 대상.
- `gf-outfit-pin.personal-extension.zip` — 확장. 게임 설정 왼쪽 목록에 [의상 캐릭터]가 생깁니다.
- `extension/` — 확장 원본
- `test/` — `node --test test/` (`GF_FORGE_SERVER=<gacha-forge-1.27.x server.mjs 경로>`를 주면 실제 파일 적용까지 검사)
- 설정 파일: `packages/server/data/gacha-outfit-pins.json` (월드 ID별 저장, 1.0.0과 같은 형식이라 그대로 이어서 씁니다)

## 설치
1. `.env`의 `NODE_OPTIONS` 끝에 `--require=.../gf-outfit-pin/gf-outfit-pin-runtime.cjs`를 넣습니다 (다른 가챠 포지 훅들보다 뒤).
2. 확장 zip을 가져와 승인·전체 페이지 접근 허용 후 켭니다.
3. 마리나라 재시작. 로그에 `[gf-outfit-pin] applied 3 edits in memory (outfit pins: pinned first, rest random)`가 보이면 정상입니다.

## 동작
- 로테이션당 의상 수: 게임 설정(`min(로테이션당 의상 수, 보유 인원)`) 그대로입니다.
- 빈 자리는 고른 캐릭터로 먼저 채웁니다. 고른 인원이 자리보다 많으면 고른 캐릭터 중 이전에 의상을 덜 받은 캐릭터부터 들어갑니다.
- 남은 자리는 고르지 않은 보유 캐릭터 중에서 무작위입니다. 게임이 이번 테마에 맞지 않는다고 거르는 캐릭터는 제외됩니다.
- 이미 다 채워진 이번 로테이션은 바뀌지 않고, 다음 로테이션부터 반영됩니다.
- 고른 캐릭터가 모두 로스터에서 빠지면 모든 자리가 무작위가 됩니다.
- 끄기: 확장에서 [모두 해제] 후 적용, 또는 `NODE_OPTIONS`에서 이 줄을 빼고 재시작.

## 1.1.0
- 고른 캐릭터만 나오던 방식(자리 수 = `min(설정, 고른 인원)`)에서, 설정한 자리 수를 유지하고 고른 캐릭터를 먼저 넣은 뒤 남은 자리를 무작위로 채우는 방식으로 바꿨습니다.
