# Gacha Forge · 의상 캐릭터 고정 1.0.0

가챠 포지 1.8.13 상점 의상 로테이션에서 **의상을 받을 캐릭터를 월드마다 고릅니다.** 고른 캐릭터들 안에서만 의상이 생성되고, 그 안에서는 이전에 의상을 덜 받은 캐릭터부터 나옵니다. 아무도 고르지 않으면 게임 기본(보유 캐릭터 전체)입니다.

커스터마이저 패치 없이도 단독으로 동작합니다.

## 구성
- `gf-outfit-pin-runtime.cjs` — 서버 훅 (메모리에서만 수정, 설치 파일은 그대로)
- `gf-outfit-pin.personal-extension.zip` — 확장. 게임 설정 왼쪽 목록에 [의상 캐릭터]가 생깁니다.
- `extension/` — 확장 원본
- 설정 파일: `packages/server/data/gacha-outfit-pins.json` (월드 ID별 저장)

## 설치
1. `.env`의 `NODE_OPTIONS` 끝에 `--require=.../gf-outfit-pin/gf-outfit-pin-runtime.cjs`를 넣습니다 (다른 가챠 포지 훅들보다 뒤).
2. 확장 zip을 가져와 승인·전체 페이지 접근 허용 후 켭니다.
3. 마리나라 재시작. 로그에 `[gf-outfit-pin] applied 4 edits`가 보이면 정상입니다.

## 동작
- 로테이션당 의상 수는 `min(이미지 설정의 로테이션당 의상 수, 고른 인원)`입니다.
- 이미 다 채워진 이번 로테이션은 바뀌지 않고, 다음 로테이션부터 반영됩니다.
- 고른 캐릭터가 모두 로스터에서 빠지면 게임 기본으로 돌아갑니다.
- 끄기: 확장에서 [모두 해제] 후 적용, 또는 `NODE_OPTIONS`에서 이 줄을 빼고 재시작.
